# AI 智能体测仪教练端 MVP 低保真原型

在线演示：<https://ai-body-coach-mvp.zhiweiwang.chatgpt.site/>  
GitHub 仓库：<https://github.com/huihui1071/ai-body-coach-mvp>

本项目根据《AI智能体测仪_教练端MVP_PRD》V1.0 制作，用于产品评审、核心流程演示和开发前需求验证。

## 已实现范围

- “工作、会员、我的”三个一级导航；
- 工作页统一承接任务、风险和待处理事项；
- 普通会员与我的私教会员；
- 普通会员无人跟进、自己跟进、他人跟进三种权限状态；
- 跟进权占用和他人跟进时的隐私脱敏；
- 完整体测报告与模拟历史对比；
- AI 专业分析审核、确认和发送；
- 跟进结果记录；
- 普通会员手动转私教会员；
- 私教会员 AI 训练方案编辑和下发；
- 待办、风险和个人服务数据。

## 样例数据说明

体测指标来自 `../ai体测仪用户样例.xlsx` 中的历史样例，经只读提取并去除生日、内部设备标识、测量 ID 等字段后使用。

原型中的姓名、手机号、门店、跟进记录和历史复测值均为演示模拟数据，不对应真实个人。页面中同时标记了“附件样例数据”和“历史值为演示模拟”。

## 演示建议

1. 首页打开林悦的新体测任务；
2. 查看完整体测报告；
3. 开始跟进并取得跟进权；
4. 生成并审核 AI 专业分析；
5. 发送报告并记录跟进结果；
6. 转为私教会员；
7. 编辑并下发训练方案；
8. 使用页面左侧演示控制切换三种普通会员权限状态。

